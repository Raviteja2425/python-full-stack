What is data?
--------------
raw facts or figures without context.
ex:101,name,5000,hyd

what is field?
--------------
smallest unit of data in database(column/attribute).
ex:ename,esalary,eaddress,eid.

what is record?
---------------
collection of related fields.
eg:(101,sunny,57789)

what is database?
-----------------
Organized collection of related records.

client server arch:
-------------------
client:the role of the client server arch is to send request to the server and to get response from the server.

server:server is a software the role of the server in client-server arch is to take request from the clients.If the 
request is valid request it it will generate some response and we can handover that response to client.
If the client request is not a valid request it will raise some error status codes.

protocol:It has a set rules and regulations.the role of the protocol in client server arch is to send request from client to server.

SQL(Structured Query language):
--------------------------------
-->Structured Query language is a standardized programming language specaily designed for managing 
and manipulating relational databases.It provides a declaration syntax that allows users define what 
data they want to retrive,insert,or delete without specifying exactly how databse should execute these 
Operation.

SQL commands:
-------------
-->DDL: Data Definition Language.

Defines and modifies the structure of data bases objects(tables,indexes)

-->DML:Data manipulation language

Manages transaction to maintain data integrity.

-->DCL: Data Control Language

Manages permissions and accesses control on database objects.

-->TCL: Transaction control language

manages transaction to maintain data integrity.

-->DQL: Data Query language

Used to fetch/retrive data from the database.
